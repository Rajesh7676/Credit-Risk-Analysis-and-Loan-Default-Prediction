# Credit-Risk-Analysis-and-Loan-Default-Prediction
End-to-end Data Analysis and Machine Learning project on Credit Risk dataset relevant to Banking and Finance GCC companies like Société Générale.


## Data Preprocessing
- Missing values handled using Median Imputation
- Outliers removed — impossible age values (>100) capped
- Extreme income outliers removed using 99th percentile
- Categorical encoding using Label Encoder

## Insights Covered
- Loan status distribution — Default vs No Default
- Loan intent wise default rate analysis
- Income vs Loan amount relationship
- Loan grade wise interest rate analysis
- Home ownership type vs Default rate

## ML Model
- Random Forest Classifier to predict Loan Default
- Accuracy: 93%
- Precision, Recall, F1 Score reported
- Confusion Matrix analyzed

## Tools Used
Python, Pandas, Matplotlib, Sklearn

## Dataset
Credit Risk Dataset from Kaggle

## Target Companies
Société Générale, HSBC, Deutsche Bank, JP Morgan GCC
